## 🛡️ Core Value Proposition & Problem Solved
Digital fraud victims often face a confusing and panic-driven first few minutes. They do not know what evidence to save, which transaction details matter, whom to contact first, or how to explain the incident clearly. This delay is fatal in financial fraud, where the official **1930 helpline** and the **Citizen Financial Cyber Fraud Reporting and Management System (CFCFRMS)** rely on reporting within the **first 60 minutes (The Golden Hour)** to freeze funds before mule networks cash out.

**Fraud First-Aid** serves as the missing, guided **first-response layer** that sits before and alongside official systems.

## ⚡ Key Features

1. **Persistent 1930 Emergency Bar & Panic CTA:**
   - 1-click `tel:1930` dialing to trigger automated inter-bank holds via CFCFRMS.
   - Quick access to `cybercrime.gov.in`.

2. **60-Minute Golden Hour Urgency Engine:**
   - Real-time elapsed timer visual countdown.
   - Explains the critical 60-minute window for halting inter-bank settlement.

3. **Multilingual UI & Web SpeechSynthesis Voice Guidance:**
   - Real-time switching between **English (EN)**, **Telugu (తెలుగు)**, and **Hindi (हिंदी)**.
   - Calibrated, calm Web SpeechSynthesis narrator with animated audio-wave indicator.

4. **Adaptive Dynamic Scenario Engine (4 Core Vectors):**
   - **UPI / Payment Fraud:** GPay, PhonePe, Paytm, QR scams, unauthorized debits, 12-digit UTR validation.
   - **Fake Job / Task Scam:** Telegram/WhatsApp ratings, prepaid deposit traps, recruiter tracking.
   - **OTP / Remote Access:** AnyDesk, TeamViewer screen takeover, unknown APK install, airplane mode isolation guide.
   - **Impersonation / Digital Arrest:** Fake Police/CBI/Customs/FedEx threats, instant video call hang-up directives.

5. **Prioritized Immediate Action Engine:**
   - Prioritized emergency steps with dynamic points (+30, +20, +15) updating response preparedness.
   - Speech reader button to speak the emergency checklist in Telugu/Hindi/English.

6. **Standardized Incident Docket & Multi-Channel Export:**
   - **One-Click Copy:** Ready for 1930 phone operators and cybercrime.gov.in.
   - **WhatsApp Share:** Instantly forward formatted emergency details to family or cyber cell.
   - **Download Official PDF:** Generates a structured A4 incident report docket with reference ID, evidence points, and audit trail via `jspdf`.

7. **Explainable Response Readiness Score (0–100):**
   - Transparent scoring model (not a fake probability) based on concrete actions taken:
     - Official reporting initiated: `+30 pts`
     - 12-digit UTR captured: `+20 pts`
     - Evidence preserved: `+15 pts`
     - Bank / payment provider contacted: `+20 pts`
     - Critical security action completed: `+15 pts`
   - Confetti celebration upon achieving response readiness.

8. **1-Click Synthetic Demo Presets (For Judges & Ideathons):**
   - `Demo 1: Fake Job Telegram Scam (₹5,000 Loss)`
   - `Demo 2: AnyDesk Remote Access & OTP Takeover (₹28,500 Loss)`
   - Demonstrates immediate dynamic adaptation of fields and action plans without typing real personal data.

9. **100% Client-Side Privacy Guarantee:**
   - Zero external server uploads. All screenshots and incident data remain strictly inside browser memory.

## 🚀 Quick Start Guide

### Prerequisites
- Node.js (v18+ or v20+)
- npm

### Installation & Run
```bash
# 1. Clone or navigate to the directory
cd Fraud_First_Aid

# 2. Install dependencies (if not already installed)
npm install

# 3. Start development server
npm run dev
# The app will be running at: http://localhost:5173/

# 4. Create production build
npm run build

# 5. Preview production build
npm run preview
```
